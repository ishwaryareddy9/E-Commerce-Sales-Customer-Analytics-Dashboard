E-Commerce Sales & Customer Analytics Dashboard

Project Overview

This project analyzes e-commerce sales data using Microsoft Power BI to understand sales performance, top-selling products, and customer insights.

Tools Used

- Microsoft Power BI
- Power Query
- Data Visualization

Key Features

- Total Sales Analysis
- Monthly Sales Trends
- Top 10 Products by Sales
- Customer and Country-wise Sales Analysis
- Interactive Dashboard Visualizations

Dataset

The project uses online retail transaction data for sales and customer analysis.

Dashboard

The Power BI report is available in this repository as "Ecommerce_customer_analytics.pbix".

Objective

To transform retail transaction data into meaningful insights that support better business decisions.
