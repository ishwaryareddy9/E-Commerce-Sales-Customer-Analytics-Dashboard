# E-Commerce Sales & Customer Analytics Dashboard

## Project Overview
This project analyzes e-commerce transaction data using Python and Microsoft Power BI to identify sales trends, top-performing products, and customer purchasing patterns. The goal is to convert raw retail data into actionable business insights.

## Tools & Technologies
- Python
- Google Colab
- Pandas and NumPy
- Microsoft Power BI
- Power Query
- Data Visualization

## Key Features
- Total Sales Analysis
- Monthly Sales Trend Analysis
- Top 10 Products by Sales
- Customer-wise Sales Analysis
- Country-wise Sales Performance
- Interactive Power BI Dashboard
- Data Cleaning and Exploratory Data Analysis (EDA)

## Project Files
- `Ecommerce_customer_analytics.pbix` — Interactive Power BI dashboard.
- `ecommerce_customer_analytics_ml.ipynb` — Python analysis notebook exported from Google Colab.

## Dataset
The project uses online retail transaction data containing information about products, customers, quantities, prices, and countries.

## Business Objectives
- Understand overall sales performance.
- Identify top-selling products.
- Analyze monthly sales patterns.
- Explore customer purchasing behavior.
- Compare sales performance across countries.
- Support data-driven business decisions.

## Key Learnings
- Data cleaning and preprocessing
- Exploratory Data Analysis (EDA)
- Sales trend analysis
- Data visualization and dashboard development
- Translating business questions into analytical insights

## How to Use
1. Open the `.ipynb` notebook in Google Colab to explore the Python analysis.
2. Open the `.pbix` file using Microsoft Power BI Desktop to explore the interactive dashboard.
